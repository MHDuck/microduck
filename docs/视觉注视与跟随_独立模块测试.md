# 独立视觉注视与前后跟随测试

前提：已完成一键部署和机器人校准。`vision-follow` 服务已开机启动，下面只使用网页；另开 `serve.py` 会造成 8091 端口冲突。

## 1. 准备

退出键盘、语音及其他控制网页，在板端停止手柄输入：

```bash
sudo systemctl stop padd
```

电脑打开 `http://板子IP:8091/`，保持网页在前台。打印 [ID0 靶标](../vision_follow/aruco_5x5_50_id0_50mm.svg)，实测黑色正方形外边长为 **50mm**。

## 2. 确认识别

1. 点击 **连接摄像头**，确认画面方向正常、持续更新。
2. 检测目标选 **ArUco · DICT_5X5_50**、ID **0**，勾选 **仅预览时启用 ArUco 识别（不控制机器人）**。
3. 将一个完整靶标放在画面中央，保持数秒，等连续识别两帧。应出现 ID0 和识别框，机器人不应运动。

## 3. 原地注视

1. 点击 **检查机器人状态（只读）**，确认状态正常。
2. 尚未站稳时，托护机器人，点击一次 **起身使能**，等待实际起身结束；已经站稳则跳过。
3. 控制方式选 **原地转头注视**，点击 **启动注视**。缓慢左右移动靶标并停住，头部应跟随转动，机身不前后走。

## 4. 前后跟随

1. 先点击 **停止控制**，再选 **转头＋前后跟随 → 停走式（ArUco）→ 图像相对大小**。
2. 将靶标放在机器人正前方、希望保持的距离，正对相机并保持不动。识别两帧后点击 **将当前距离设为跟随距离**，确认记录出现“已设定跟随目标”。
3. 点击 **启动前后跟随**。靶标保持在基准位置时应停车；移远应前进，移近应后退，回到基准附近应停止。

默认每段走 2.5 秒、停稳 1 秒再识别，不会随靶标移动立即换向。需要立即停车时点击 **停止控制**，或让网页获得焦点后按空格 / Esc。

先选模式再设基准；刷新页面、更改检测目标或跟随依据后，需要重新设置。此次测试使用相对大小，不填写米数。

## 5. 结束

点击 **停止控制**，再断开连接。停止不卸力；视觉服务继续运行，下次直接打开网页。
恢复手柄时，在板端执行 `sudo systemctl start padd`。

安装、更新与排错见[视觉功能一键部署与使用](视觉功能_全新WSL与板端部署.md)。
