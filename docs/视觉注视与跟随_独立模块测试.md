# 独立视觉注视与前后跟随测试

全新电脑/板子先按[完整部署指南](视觉功能_全新WSL与板端部署.md)安装；本页用于日常测试。

## ArUco（推荐）

WSL 仓库根目录：

```bash
export BOARD=radxa@192.168.2.70
sh vision_follow/push.sh "$BOARD"
```

板端先退出旧 serve.py，使用已有视觉环境：

```bash
cd "$HOME/microduck-vision"
.venv/bin/python serve.py --detector aruco --marker-id 0 --marker-mm 50
```

打开 http://板子IP:8091/：

1. 停其他控制客户端。连接摄像头，不识别/使能，确认视频连续正常。
2. 勾识别预览，放入 DICT_5X5_50、ID0、黑色外边 50mm 的码，应画框而无运动。
3. 检查机器人状态，人工“起身使能”；区分请求入队和实际起身，等待结束站稳。
4. 原地注视并启动，左右移动码，应转头不平移；可选上下看。
5. 停止控制。期望位置两帧稳定后“将当前距离设为跟随距离”。
6. 选“转头＋前后跟随”、停走式、图像相对大小，启动后移远/移近码：
   前进/后退最多一段 2.5 秒，停稳 1 秒再识别。接近目标大小应停步。
7. 停止按钮或空格 / Esc 停控；下载日志，再断开连接。

预览开关只管非控制时识别，不勾选也可控制；控制中取消勾选不会关闭控制。
一次只用一个控制者。停止清零速度，不卸力、不自动回正头，也不取消主程序已经接受的恢复。
不自动转身、横移或避障。

## 原鸭子检测模式

使用 mediad 已有模型通知，不由 Python 加载新模型/打开摄像头；仅运行网页不需要 OpenCV：

```bash
python3 "$HOME/microduck-vision/serve.py" --detector duck --follow-style continuous
```

先预览、人工起身，再注视；按框高做相对大小跟随。
鸭子模式没有 ArUco 主动采样的停走流程，使用连续式；detector 模型与 NPU 须已正常安装。
ArUco 不依赖鸭子模型。头部仍由站立/行走策略响应，不直接控制舵机。

## 验收与退出

记录视频持续性、ID/框方向、起身是否开始、head 指令/实测关节、
moving/stopping/settling/detecting 阶段和停止原因。先注视后行走，实测与指令分开判断。

网页停控、断开，视觉终端 Ctrl-C。恢复键盘：

```bash
sudo systemctl restart robotd
sudo python3 /opt/robot/daemon/current/scripts/keyboard-control.py --speech off
```
