# 相机方向：统一追加 180° 修正

适用：相机相对原显示上下颠倒，需要再转 180°。本功能在 mediad 统一解析方向，
默认 offset=0 保持其他机器行为，不改 IMU 安装方向、舵机、模型或任务衔接。
主程序已就绪时，新增视觉模块见[视觉部署与操作测试](视觉功能_全新WSL与板端部署.md)；
本文另行说明 mediad 方向功能的编译与替换。

新刷 Armbian 后通过 `scripts/provision-board.sh` 一键部署，已包含本功能的 mediad、方向配置与视觉服务，无需手动替换。默认追加 180°、`pixels=false`；重跑部署保留已有 `/etc/systemd/system/mediad.service.d/20-camera-orientation.conf`。以下步骤用于手动更新已有板子的 mediad。

## 输出模式

DUCK_CAMERA_ROTATE_OFFSET=180 叠加原 --rotate（默认 90），结果为 270。
CLI --rotate-offset 覆盖环境配置；只接受 0、90、180、270。

| DUCK_CAMERA_ROTATE_PIXELS | 行为 |
| --- | --- |
| false（推荐） | 保留编码原始像素和零拷贝，8080/8091 和检测消费统一方向元数据；新视频消费者须应用 media.video.rotate。原始标定照片仍是 raw 像素。 |
| true | 编码与检测分流前实际旋转，报告剩余 rotate=0，90/270 时交换宽高；增加处理开销，须确认帧率/温度并重标定。 |

## 已有板子编译与替换 mediad

vision_follow/push.sh 只更新独立视觉模块；master 的 xh_push.sh 会同步 mediad。
已有板子也可按以下步骤单独编译、备份并替换 mediad。
WSL 已准备构建环境后，在仓库根目录执行：

```bash
export BOARD=radxa@192.168.2.70
source "$HOME/.cargo/env"
cargo fetch --locked
sh scripts/cross-sysroot.sh
export PKG_CONFIG_SYSROOT_DIR="$PWD/deploy/sysroot"
export PKG_CONFIG_LIBDIR="$PKG_CONFIG_SYSROOT_DIR/usr/lib/aarch64-linux-gnu/pkgconfig:$PKG_CONFIG_SYSROOT_DIR/usr/share/pkgconfig"
export PKG_CONFIG_ALLOW_CROSS=1
export RUSTFLAGS="-L $PKG_CONFIG_SYSROOT_DIR/usr/lib/aarch64-linux-gnu"
bash build.sh -p mediad
scp target/native/aarch64-unknown-linux-gnu/release/mediad "$BOARD:/tmp/mediad-camera-new"
scp mediad/systemd/20-camera-upside-down.conf.example "$BOARD:/tmp/20-camera-orientation.conf"
```

网页停止控制、断开视频，板端：

```bash
camera_backup="/var/backups/mediad-camera-$(date +%Y%m%d-%H%M%S)"
sudo install -D -m 755 /opt/robot/daemon/current/bin/mediad "$camera_backup"
echo "原 mediad 备份：$camera_backup"
sudo mkdir -p /etc/systemd/system/mediad.service.d
sudo install -m 644 /tmp/20-camera-orientation.conf \
  /etc/systemd/system/mediad.service.d/20-camera-orientation.conf
sudo systemctl stop mediad
sudo install -m 755 /tmp/mediad-camera-new /opt/robot/daemon/current/bin/mediad
sudo systemctl daemon-reload
sudo systemctl start mediad
sudo journalctl -u mediad -n 30 --no-pager
```

示例为 offset=180、pixels=false。用 sudoedit 修改
/etc/systemd/system/mediad.service.d/20-camera-orientation.conf 后重启 mediad 生效，不重启 robotd。

## 验证与回退

1. 8080/8091 刷新重连，方向纸确认在旧图上再转 180；ArUco 框应与图一致。
2. 原角度 90 时，false 模式日志 pixel_rotation=0、consumer_rotation=270；
   true 模式 pixel_rotation=270、consumer_rotation=0，原 1280×720 编码变为 720×1280。
3. 不在网页额外旋转。实际编码像素旋转后先移除旧 --calibration、重新采集 raw 照片标定；
   即使 180° 后宽高相同也不能直接沿用内参。
4. true 负载过大可改 false，方向仍修正；恢复原方向则 offset=0、pixels=false，再重启 mediad。
5. 恢复二进制时先停止 mediad，将上面打印的备份 install 回原路径，再启动。

统一方向不解决摄像头停流或总线故障，不清除保护、不自动恢复控制。
